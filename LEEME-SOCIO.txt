PASSCODE — cómo probarlo en tu compu
=====================================

1) Instalá Python 3.11 o más nuevo: https://www.python.org/downloads/
   (en el instalador tildá "Add python.exe to PATH").

2) Descomprimí este .zip. Abrí la carpeta "passcode", hacé clic en la barra de
   direcciones del Explorador, escribí  cmd  y Enter. En la ventana negra:

     python -m venv venv
     venv\Scripts\activate
     pip install -r requirements.txt
     python run.py

3) Abrí http://localhost:5000 en el navegador.

USAR LA APP DESDE INTERNET (celular, otras personas) CON NGROK — opcional
--------------------------------------------------------------------------
Para probar solo en esta compu NO hace falta: alcanza con http://localhost:5000.

1) Creá una cuenta gratis en https://ngrok.com
2) Instalá ngrok: en la ventana negra escribí
     winget install ngrok.ngrok
   (cerrá y volvé a abrir la ventana negra después de instalarlo)
3) Copiá tu "Authtoken" del panel de ngrok (Your Authtoken) y escribí:
     ngrok config add-authtoken TU_AUTHTOKEN
4) En el panel de ngrok, en "Domains", reclamá tu dominio gratis
   (algo como  tu-nombre.ngrok-free.dev).
5) Con la app corriendo (python run.py), abrí OTRA ventana negra y escribí:
     ngrok http --url=https://TU-DOMINIO.ngrok-free.dev 5000
6) Abrí el archivo .env con el Bloc de notas y cambiá:
     BASE_URL=https://TU-DOMINIO.ngrok-free.dev
   Guardá y volvé a correr  python run.py
7) Entrá a la app desde https://TU-DOMINIO.ngrok-free.dev (si aparece un aviso de
   ngrok, tocá "Visit Site").

Con BASE_URL en https, la app apaga sola el modo de depuración (más seguro) y
Mercado Pago puede avisar automáticamente los pagos en efectivo.
